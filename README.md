# The Safe Room - Podcast Promotional Website

A promotional webpage for "The Safe Room" podcast - your sanctuary for honest conversations.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI**: Clean and professional design with smooth animations
- **Easy Navigation**: Fixed header with smooth scrolling to sections
- **Episode Showcase**: Display latest podcast episodes
- **Platform Links**: Quick links to all major podcast platforms
- **Social Media Integration**: Connect with your audience on social platforms

## Structure

```
.
├── index.html          # Main HTML file
├── styles.css          # Stylesheet with responsive design
├── script.js           # JavaScript for interactivity
├── assets/             # Assets directory
│   └── images/         # Images folder
└── README.md           # This file
```

## Sections

1. **Home/Hero**: Welcome section with call-to-action
2. **About**: Brief description of the podcast
3. **Episodes**: Showcase of latest episodes
4. **Subscribe**: Links to all podcast platforms
5. **Contact**: Social media and contact information

## Usage

1. Open `index.html` in a web browser to view the website
2. Customize the content in `index.html` to match your podcast details
3. Add your podcast artwork and images to the `assets/images/` folder
4. Update platform links in the Subscribe section with actual URLs
5. Update social media links in the Contact section

## Customization

### Colors
The default color scheme uses purple gradients. To change:
- Edit the gradient colors in `styles.css`
- Search for `#667eea` and `#764ba2` to update the primary colors

### Content
- Update episode information in the Episodes section
- Modify the About section with your podcast description
- Change the tagline and welcome message in the Hero section

### Images
- Add your podcast logo/artwork to `assets/images/`
- Update image references in `index.html`

## Browser Compatibility

Compatible with all modern browsers:
